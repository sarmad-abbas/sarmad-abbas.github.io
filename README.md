# Sarmad Abbas — Portfolio

Live at https://sarmad-abbas.github.io/

A static React portfolio adapted from Arfazrll’s MIT-licensed PersonalBlog template. The original hero, spotlight, profile card, card navigation and editorial introduction are personalized for Sarmad’s security studies and development experience.

## Editing
Extract `portfolio-source.zip`, run `npm ci`, then `npm run build`. Deploy `dist/index.html` to the repository root. The bundle contains its own scripts, styles and fonts; no server or secrets are required.

Profile content and project data are in `src/main.tsx` and `src/data/portfolio.ts`. The hero is in `src/components/sections/HeroVisual.tsx`; styling is in `src/style.css`.
